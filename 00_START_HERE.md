# START HERE - Applied AI and Machine Learning in 4 Days

Welcome. This course teaches you Artificial Intelligence (AI) and Machine Learning (ML) **by reading a little and then doing a lot**.

You do **not** need to know AI, Machine Learning or advanced maths. Everything is explained in simple English, with small examples from daily life. Basic Python helps, but Day 1 shows every line you need to type.

---

## How every lesson works

Every lesson has the same parts, in the same order:

| Part | What you do |
|---|---|
| **Goal** | Read what you will be able to do at the end. |
| **Understand** | Read a short, simple explanation (the theory). |
| **Do it now** | Open the notebook or type the commands **exactly** as shown (the practical). |
| **Check** | Compare your screen with what you *should* see. |
| **What just happened?** | Read what your code actually did. |
| **Try it yourself** | A small challenge so you really learn it. |
| **If it does not work** | The most common mistakes and how to fix them. |

**Golden rule:** do not move to the next lesson until the **Check** of the current lesson works.

---

## Two kinds of files you will use

1. **Lessons** - files ending in `.md` (for example `01_WHAT_IS_AI.md`). These are for **reading**. Open them in VS Code and press **Ctrl + Shift + V** to see them nicely formatted.
2. **Notebooks** - files ending in `.ipynb` (for example `01_How_Machines_Learn.ipynb`). These are for **doing**. A notebook is a page that mixes explanation and small boxes of Python code. You run each box with **Shift + Enter** and see the answer right below it. Day 1 Lesson 02 shows you how to open them.

## No API key? You can still do everything

On Day 2 and Day 3 we talk to a real AI model (Google Gemini) through the internet. This needs a free **API key** (a secret password for programs).

If you cannot get a key, or the internet is slow, or you run out of free requests, all our code switches to **MOCK mode** automatically. Mock mode is a pretend AI that gives simple offline answers, so your code still runs and you can keep learning. You will see a line like `[MOCK MODE]` in the output when this happens.
