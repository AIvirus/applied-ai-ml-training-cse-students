# Glossary

Every new word from the course, in simple English, in alphabetical order. The day and lesson where it is taught are in brackets.

| Word | Simple meaning |
|---|---|
| **Accuracy** | Share of all predictions that were correct. (D1 L08) |
| **Activation function** | Formula inside a neuron that decides its output and lets networks learn curved patterns, for example ReLU or sigmoid. (D2 L01) |
| **Agent (AI agent)** | An LLM that works towards a goal by choosing and using tools in a loop. (D2 L09) |
| **Algorithm** | A step-by-step recipe. In ML, a recipe for learning a pattern from data. (D1 L07) |
| **API** | A fixed way for one program to ask another program for data or actions. (D2 L06) |
| **API key** | A secret password that identifies your program to an API. Never share it. (D2 L06) |
| **Artificial Intelligence (AI)** | Computers doing tasks that normally need human intelligence. (D1 L01) |
| **Attention** | The Transformer mechanism that decides which other words matter most for each word. (D2 L05) |
| **Backpropagation** | Working out how much each weight caused the error, going backwards through the network. (D2 L01) |
| **Bag of Words** | Turning text into word counts, ignoring order. (D2 L02) |
| **Batch** | A small group of training examples processed before one weight update. (D2 L01) |
| **Bias (in a neuron)** | A number added to the weighted sum that shifts the result. (D2 L01) |
| **Bias (unfairness)** | When a model treats groups unfairly, often learned from unfair data. (D2 L10) |
| **Bias (statistics)** | Error from a model that is too simple; causes underfitting. (D1 L08) |
| **Big data** | Data too big, fast or varied for one normal computer (Volume, Velocity, Variety). (D1 L05) |
| **Branch** | A separate line of work in Git. (D4 L03) |
| **CI/CD** | Continuous Integration (test every change automatically) and Continuous Delivery/Deployment (release tested changes). (D4 L08) |
| **Chunk** | A small piece of a document used for search and RAG. (D2 L08) |
| **Classification** | Predicting a category, like pass/fail. (D1 L03) |
| **Clustering** | Grouping data without labels, for example with K-means. (D1 L07) |
| **CNN** | Convolutional Neural Network; uses small filters, mainly for images. (D2 L01, L03) |
| **Commit** | A saved snapshot of your project in Git, with a message. (D4 L02) |
| **Computer Vision** | AI that understands images and video. (D2 L03) |
| **Confusion matrix** | A table of true/false positives and negatives. (D1 L08) |
| **Container** | A running copy of a Docker image. (D4 L04) |
| **Context window** | The maximum number of tokens an LLM can see at once. (D2 L05) |
| **Correlation** | How two things move together, from -1 to +1. (D1 L04) |
| **Cosine similarity** | How similar two vectors are, from 0 (unrelated) to 1 (same direction). (D2 L08) |
| **Cross-validation** | Testing a model on several different splits and averaging the scores. (D1 L08) |
| **CSV** | A text file of a table, values separated by commas. (D1 L05) |
| **Data leakage** | Accidentally giving the model the answer as a feature. (D1 L06) |
| **Data science** | Getting knowledge and predictions from data using statistics and ML. (D1 L05) |
| **DataFrame** | pandas' name for a table. (D1 L05) |
| **Dataset** | A collection of examples, usually a table. (D1 L03) |
| **Decision tree** | A model that asks a series of yes/no questions. (D1 L07) |
| **Deep Learning** | ML with neural networks that have many layers. (D1 L01, D2 L01) |
| **Deployment** | Making your app run on a server for others to use. (D4 L07) |
| **Discriminative model** | A model that labels or decides (spam or not). (D2 L05) |
| **Docker** | A tool that packs an app with everything it needs into an image. (D4 L04) |
| **Dockerfile** | The recipe to build a Docker image. (D4 L05) |
| **EDA** | Exploratory Data Analysis: getting to know data before modelling. (D1 L05) |
| **Edge AI** | Running AI on the device itself instead of the cloud. (D2 L04) |
| **Embedding** | A list of numbers that represents the meaning of text (or images). (D2 L02, L08) |
| **Encoding** | Turning categories into numbers, for example one-hot encoding. (D1 L06) |
| **Endpoint** | One address of an API that does one job, like `POST /api/ask`. (D3 L01) |
| **Environment variable** | A setting given to a program from outside its code, like `GEMINI_API_KEY`. (D2 L06, D4 L05) |
| **Epoch** | One full pass over all the training data. (D1 L08) |
| **Explainable AI (XAI)** | Methods that show why a model made a decision. (D2 L04) |
| **F1-score** | One number balancing precision and recall. (D1 L08) |
| **FastAPI** | A Python framework for building APIs. (D3 L04) |
| **Feature** | An input column the model uses (X). (D1 L03) |
| **Feature engineering** | Creating new, more useful features from existing data. (D1 L06) |
| **Few-shot prompting** | Giving a few examples in the prompt. (D2 L07) |
| **Fine-tuning** | Extra training of a pre-trained model on focused data. (D2 L05) |
| **Generative AI** | AI that creates new content: text, images, audio, code. (D2 L05) |
| **Git / GitHub** | Version control tool / website that hosts Git repositories. (D4 L02, L03) |
| **GitHub Actions** | GitHub's tool for running automated workflows like tests. (D4 L08) |
| **Gradient descent** | Improving a model step by step by moving "downhill" on the loss. (D1 L04) |
| **Hallucination** | A confident but false answer from an AI. (D2 L10) |
| **Health check** | An endpoint (like `/health`) that shows the app is alive. (D3 L04, D4 L09) |
| **Image (Docker)** | A built, read-only package of an app and its environment. (D4 L04) |
| **Inference** | Using a trained model to make predictions or answers. (D2 L05) |
| **Jupyter notebook** | A file (`.ipynb`) with text and runnable code cells. (D1 L02) |
| **K-means** | A clustering algorithm that finds K groups. (D1 L07) |
| **KNN** | K-Nearest Neighbours: predicts from the K most similar examples. (D1 L07) |
| **Label** | The answer the model should predict (y). Also called target. (D1 L03) |
| **Lemmatisation** | Reducing a word to its dictionary form (studies -> study). (D2 L02) |
| **Linear regression** | Predicts a number with the best straight line. (D1 L07) |
| **LLM** | Large Language Model: a huge neural network trained to predict the next token. (D2 L05) |
| **Log** | A recorded line about what a program did. (D4 L09) |
| **Logistic regression** | Predicts the probability of a class. (D1 L07) |
| **Loss** | A number measuring how wrong a model is. (D1 L04, L08) |
| **Machine Learning (ML)** | Computers learning rules from examples instead of being programmed with them. (D1 L01, L03) |
| **MAE** | Mean Absolute Error: average size of prediction mistakes. (D1 L08) |
| **MCP** | Model Context Protocol: an open standard to connect AI apps to tools and data. (D2 L09) |
| **Mean / median / mode** | Average / middle value / most common value. (D1 L04) |
| **Middleware** | Code that runs for every request in a web app. (D3 L04) |
| **Mock mode** | Our offline pretend-AI that keeps code working without an API key. (D2 L06, D3) |
| **Multimodal** | Understands several kinds of input: text, images, audio. (D2 L05) |
| **MVP** | Minimum Viable Product: the smallest useful version. (D3 L01) |
| **N-gram** | A group of n words in a row. (D2 L02) |
| **NER** | Named Entity Recognition: finding names of people, places, organisations. (D2 L02) |
| **Neural network** | Layers of connected artificial neurons. (D2 L01) |
| **NLP** | Natural Language Processing: AI for human language. (D2 L02) |
| **OCR** | Optical Character Recognition: reading text from images. (D2 L03, D3 L11) |
| **Outlier** | A value very far from the others. (D1 L06) |
| **Overfitting** | A model memorises training data and fails on new data. (D1 L08) |
| **Parameters** | The learned numbers (weights and biases) inside a model. (D2 L05) |
| **Pipeline (scikit-learn)** | Steps joined together, like scaling then a model. (D1 L07) |
| **Port** | A numbered "door" on a computer that a server listens on, like 8000. (D3 L04, D4 L05) |
| **Pre-training** | The first, huge training of an LLM on general text. (D2 L05) |
| **Precision** | When the model says positive, how often it is right. (D1 L08) |
| **Prompt** | The instruction or question sent to an LLM. (D2 L07) |
| **Prompt engineering** | Writing prompts that give good, reliable results. (D2 L07) |
| **Prompt injection** | Hidden instructions in input or data that try to take control of an AI. (D2 L10) |
| **Pull request** | A request to merge a branch, with review. (D4 L03) |
| **Pydantic** | A Python library that checks data has the right shape and types. (D2 L07) |
| **RAG** | Retrieval-Augmented Generation: find relevant text, then let the LLM answer using it. (D2 L08) |
| **Random forest** | Many decision trees that vote. (D1 L07) |
| **Recall** | Of all real positives, how many the model found. (D1 L08) |
| **Recommender system** | Suggests items a user may like. (D2 L04) |
| **Regression** | Predicting a number. (D1 L03) |
| **Reinforcement learning** | Learning by trial and error with rewards. (D1 L03, D2 L04) |
| **Reranking** | Re-ordering retrieved chunks with a more careful method. (D2 L08) |
| **Repository** | A project folder tracked by Git. (D4 L02) |
| **RNN** | Recurrent Neural Network; reads sequences one item at a time with memory. (D2 L01) |
| **Scaling** | Putting features on similar ranges. (D1 L06) |
| **Semantic search** | Searching by meaning, using embeddings. (D2 L08) |
| **Semi-supervised learning** | Learning from a few labelled and many unlabelled examples. (D1 L03) |
| **Sentiment analysis** | Finding if text is positive, negative or neutral. (D2 L02) |
| **Standard deviation** | Typical distance of values from the mean. (D1 L04) |
| **Stemming** | Chopping word endings (studies -> studi). (D2 L02) |
| **Stop words** | Very common words like "the", "is". (D2 L02) |
| **Structured / unstructured data** | Table data / free-form data like text and images. (D1 L05) |
| **Supervised learning** | Learning from examples with answers (labels). (D1 L03) |
| **SVM** | Support Vector Machine: finds the widest road between classes. (D1 L07) |
| **System instruction** | Developer-written rules and role for an LLM. (D2 L07) |
| **Temperature** | Controls how random an LLM's word choice is. (D2 L05) |
| **Test set** | Data kept aside for the final, honest evaluation. (D1 L08) |
| **TF-IDF** | Word score that is high for words frequent in one document but rare overall. (D2 L02) |
| **Token** | A piece of text (often part of a word) that an LLM reads. (D2 L05) |
| **Tokenisation** | Splitting text into tokens. (D2 L02, L05) |
| **Tool calling** | An LLM asking your code to run a function with given inputs. (D2 L09) |
| **Training set** | Data the model learns from. (D1 L08) |
| **Transfer learning** | Re-using a pre-trained model for a new task. (D2 L03) |
| **Transformer** | The neural network design behind modern LLMs, based on attention. (D2 L05) |
| **Underfitting** | A model too simple to learn the pattern. (D1 L08) |
| **Unsupervised learning** | Finding patterns in data without labels. (D1 L03) |
| **Uvicorn** | The server program that runs FastAPI apps. (D3 L04) |
| **Validation set** | Data used to choose models and settings. (D1 L08) |
| **Variance (statistics)** | How spread out values are. (D1 L04) |
| **Variance (model)** | A model changing too much with small data changes; causes overfitting. (D1 L08) |
| **Vector** | An ordered list of numbers. (D1 L04) |
| **Vector database** | A database built to store vectors and find similar ones fast. (D2 L08) |
| **Vibe coding** | Building software by describing it in normal language to an AI assistant. (D3 L02) |
| **Virtual environment** | A private folder of packages for one project (`.venv`). (D1 L02) |
| **Virtual machine (VM)** | A full computer simulated in software, with its own operating system. (D4 L04) |
| **Weights** | Numbers that say how important each input is to a neuron. (D2 L01) |
| **Word2Vec** | An early method that learns word embeddings from text. (D2 L02) |
| **XSS** | Cross-site scripting: an attack where text becomes code in a web page. (D3 L09) |
