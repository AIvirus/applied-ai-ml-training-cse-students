# Lesson 01 - What is AI?

**Time:** 35 minutes  |  **You need:** nothing, just read

---

## Goal

By the end of this lesson you can explain, in your own words:

- what Artificial Intelligence (AI) means,
- a short history of AI,
- where AI is used today,
- the difference between **narrow AI** and **general AI**,
- the difference between **AI** and **automation**,
- how **AI**, **Machine Learning** and **Deep Learning** are related.

---

## Understand

### 1. What does "Artificial Intelligence" mean?

- **Artificial** = made by people (not natural).
- **Intelligence** = the ability to learn, understand, decide and solve problems.

So **Artificial Intelligence** is when we make computers do tasks that normally need human intelligence.

Examples of such tasks:

| Human skill | AI example you have already used |
|---|---|
| Seeing | Your phone unlocks when it sees your face |
| Hearing | "Hey Google" or Siri understands your voice |
| Reading and writing | ChatGPT, Gemini and Claude answer questions and write text |
| Deciding | Google Maps picks the fastest route |
| Recommending | YouTube suggests the next video you may like |
| Translating | Google Translate turns Hindi into English |

**Simple definition to remember:** AI is a computer program that does something "smart" which used to need a human.

### 2. A short history of AI

You do not need to remember dates. Just see that AI grew step by step.

| Year | What happened | Why it matters |
|---|---|---|
| 1950 | Alan Turing asks "Can machines think?" and proposes the **Turing Test** | The question that started the field |
| 1956 | The word "Artificial Intelligence" is first used at a meeting at Dartmouth College, USA | AI becomes a subject of study |
| 1960s-1980s | **Rule-based** programs and "expert systems" (thousands of if-else rules written by experts) | Worked for small problems, broke on real-world mess |
| 1970s and late 1980s | **AI winters** - money and interest dropped because AI promised too much | Teaches us to avoid hype |
| 1997 | IBM's Deep Blue beats the world chess champion Garry Kasparov | A computer beats a human in a "thinking" game |
| 2000s | The internet creates huge amounts of **data**; computers get faster | Machine Learning starts to work well |
| 2012 | A **deep learning** model (AlexNet) wins a big image recognition contest by a large margin | Start of the deep learning boom |
| 2016 | Google DeepMind's AlphaGo beats a world champion at the game Go | Learned by playing against itself |
| 2017 | Google researchers publish the **Transformer** ("Attention Is All You Need") | The design behind today's chatbots |
| 2022 onwards | ChatGPT, then Gemini, Claude, Llama and many more | **Generative AI** reaches everyone |

### 3. Where is AI used today?

| Field | Example |
|---|---|
| Healthcare | Spotting diseases in X-ray and scan images |
| Banking and finance | Catching fraud in card payments |
| Shopping | "Customers who bought this also bought..." |
| Farming | Detecting crop disease from a leaf photo |
| Transport | Self-driving features, traffic prediction |
| Education | Personal tutors, auto-checking of answers |
| Software engineering | AI coding assistants that write and explain code |
| Cybersecurity | Finding unusual network activity (possible attacks) |
| Manufacturing | Finding defects in products on a camera line |

### 4. Narrow AI and General AI

- **Narrow AI** (also called weak AI) is good at **one kind of task**. A chess program cannot drive a car. A face-unlock system cannot write a poem. **Every AI that exists today is narrow AI**, even the big chatbots (they are very wide, but they still make mistakes a human would not make and cannot do everything a human can).
- **General AI** (also called AGI, Artificial General Intelligence) would be an AI that can learn and do **any** intellectual task a human can do, at human level. It is an **idea and a research goal**. People disagree about if and when it will happen.

### 5. AI versus automation

These two words are often mixed up.

| | Automation | AI |
|---|---|---|
| How it works | Follows **fixed rules** written by a person | **Learns patterns** from data (or reasons in a flexible way) |
| Example | A washing machine programme: wash 20 min, rinse 10 min, spin 5 min | A spam filter that learns new kinds of spam emails by itself |
| New situation | Does the same thing every time, even if it is wrong | Can handle cases it has never seen before (not always correctly) |
| Is it AI? | No | Yes |

**Example:** an automatic street light that turns on at 6:00 PM is automation. A street light camera that **recognises** that there is fog and turns on early is AI.

### 6. AI, Machine Learning and Deep Learning

Think of three circles, one inside the other:

```text
+-------------------------------------------------------------+
|  ARTIFICIAL INTELLIGENCE (AI)                               |
|  Any technique that makes computers act smart.              |
|  (includes hand-written rules, search, planning, and ML)    |
|                                                             |
|   +-----------------------------------------------------+   |
|   |  MACHINE LEARNING (ML)                              |   |
|   |  The computer LEARNS rules from examples (data)     |   |
|   |  instead of a person writing every rule.            |   |
|   |                                                     |   |
|   |   +---------------------------------------------+   |   |
|   |   |  DEEP LEARNING (DL)                         |   |   |
|   |   |  ML that uses big "neural networks" with    |   |   |
|   |   |  many layers. Powers face unlock, voice     |   |   |
|   |   |  assistants and chatbots like Gemini.       |   |   |
|   |   +---------------------------------------------+   |   |
|   +-----------------------------------------------------+   |
+-------------------------------------------------------------+
```

- All Deep Learning is Machine Learning.
- All Machine Learning is AI.
- But not all AI is Machine Learning (for example, a chess program with hand-written rules is AI but not ML).

**Data Science** is a close friend of these circles: it is about getting useful knowledge from data. It uses statistics, charts **and** machine learning. You will learn it in Lesson 05.

**Generative AI** (Day 2) is a part of Deep Learning that **creates new content** - text, images, music, code.

## Do it now

No code in this lesson. Do this small activity on paper or in a text file.

For each item, write **AI** or **Automation** and one line explaining why:

1. A lift (elevator) that goes to the floor you press.
2. Gmail moving an email to the Spam folder.
3. A microwave that stops after 2 minutes.
4. Your phone camera blurring the background behind a person in "portrait mode".
5. A bank app that blocks a card payment because it looks unusual.
6. An alarm clock that rings at 6:00 AM.

---

## Check

Compare with these answers:

1. Automation - fixed rule: button pressed, go to floor.
2. AI - it learned from millions of emails what spam looks like.
3. Automation - fixed timer.
4. AI - it must **recognise** where the person is in the picture.
5. AI - it learned the normal spending pattern of the customer.
6. Automation - fixed time.

If you got at least 5 of 6 right, you understand the difference.

---

## What just happened?

You learned that:

- AI = computers doing "smart" tasks that needed humans.
- Today's AI is **narrow AI**. General AI is an idea for the future.
- Automation follows fixed rules. AI learns or reasons from data.
- Deep Learning is inside Machine Learning, which is inside AI.

## If it does not work

| Problem | Fix |
|---|---|
| "I still cannot tell AI from automation" | Ask: "Does it follow a fixed rule a person wrote, or did it learn from examples?" Fixed rule = automation. |
| "Is a calculator AI?" | No. It follows exact maths rules. It never learns. |
| "Is ChatGPT general AI?" | No. It is a very capable narrow AI. It can still make confident mistakes (called hallucinations - Day 2). |
