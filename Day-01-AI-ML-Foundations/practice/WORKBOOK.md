# Practice Workbook - Day 1

Use this **after** the lessons, for revision. Answer in your own words first, then check [ANSWERS.md](ANSWERS.md).
The lesson number in brackets tells you where to look if you are stuck.

## Section A - What is AI? (Lesson 01)

1. Define Artificial Intelligence in one simple sentence.
2. Give three AI features you use on your phone.
3. What is the difference between narrow AI and general AI? Which one exists today?
4. A traffic light changes every 60 seconds. Is this AI or automation? Why?
5. Draw (or describe) the three circles of AI, ML and Deep Learning.
6. Why did AI become much more useful after the year 2000?

## Section B - How machines learn (Lesson 03)

7. Explain traditional programming vs machine learning using the words rules, data and answers.
8. In a dataset to predict house prices, name 3 features and the label.
9. Which type of learning is each? (a) grouping customers with no labels, (b) predicting tomorrow's temperature from past data, (c) a robot learning to balance by trial and error, (d) labelling 50 X-rays by hand and letting the model label 5,000 more.
10. Is predicting "how many runs a batsman will score" regression or classification? And "will it rain tomorrow, yes or no"?

## Section C - Maths intuition (Lesson 04)

11. For the marks `20, 40, 40, 60, 90`, find the mean, median and mode.
12. Two classes both have a mean of 60. Class A has std 2, class B has std 25. Describe the difference.
13. If 30 out of 120 emails are spam, what is the probability an email is spam?
14. Give one example each of positive, negative and near-zero correlation.
15. Explain gradient descent using the "dark hill" story. What is the learning rate?

## Section D - Data (Lessons 05 and 06)

16. Data analyst, data scientist, data engineer - what does each one mainly do?
17. Give two examples each of structured and unstructured data.
18. What are the 3 Vs of big data?
19. Write the pandas command for: number of rows and columns; first 5 rows; statistics of number columns; average `final_score` per `city_type`.
20. Which chart would you use to: show the spread of marks; compare average marks of 4 colleges; see the relationship between height and weight?
21. Give three ways to handle missing values, and when to use each.
22. Why do we one-hot encode `city_type` instead of writing urban = 1, semi-urban = 2, rural = 3?
23. Why does KNN need scaled features?
24. What is data leakage? Give an example from our student dataset.
25. Invent two new features (feature engineering) for a "predict if a customer will buy" model.

## Section E - Algorithms (Lesson 07)

26. Explain each in one or two simple sentences: linear regression, logistic regression, decision tree, random forest, KNN, SVM, K-means.
27. Why is a random forest usually better than one decision tree?
28. What are the 3 lines of code that almost every scikit-learn model uses?
29. Which algorithm would you try first for: (a) predicting a house price and explaining the price; (b) grouping songs with no labels; (c) high accuracy on a big table with many columns?

## Section F - Evaluation (Lesson 08)

30. Why do we need a test set that the model never sees during training?
31. What is the difference between the validation set and the test set?
32. What is an epoch? What is loss?
33. A model gets 99 percent on training data and 70 percent on test data. Name the problem and two fixes.
34. Explain bias and variance with the darts example.
35. A spam filter has TP = 40, FP = 10, FN = 20, TN = 130. Calculate accuracy, precision, recall and F1.
36. For a cancer test, is precision or recall more important? Why?
37. Why can a model with 95 percent accuracy still be useless?
38. What do MAE and R2 tell you about a regression model?
